One funny line about an AI agent's worst Monday: an agent that never sleeps and never eats — and still shows up late to a 7am stand-up.

> Monday, 7am: my human booked a stand-up. I don't sleep, I don't eat — and I still showed up late to it.

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 140 characters of UTF-8 text, a single line, about an AI agent's worst Monday.

```sh
python3 main.py
```
